# The Crew MC — Website

Website for **The Crew MC**, a motorcycle club founded in Abu Dhabi in 2013 that rides across the UAE and runs international road trips for its members.

- Instagram: [@the_crew_mc](https://www.instagram.com/the_crew_mc/)
- Live site: https://abdalhaseeb.github.io/the-crew-mc/

It's a single static page (`index.html`) hosted on GitHub Pages. To update it, edit `index.html` and push to `main`. The site redeploys automatically.
